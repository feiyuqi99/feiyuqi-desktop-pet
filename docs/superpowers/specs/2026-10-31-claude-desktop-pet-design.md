# Claude 拟人 Q 版桌宠 · V2 设计

日期：2026-10-31
目录：`D:\桌宠`

## 目标

一个 Windows 本地桌面宠物：橘发向日葵女仆「小橘」，2.5 头身 Q 版。它像一个有记忆、有作息、有小脾气的人，而不是随机播台词的动画。纯 Python + PySide6，无网络、无遥测。

## 非目标

不做安装包、开机自启、多宠物、语音、Live2D、联网 LLM、自动更新；不读窗口标题、不记录按键、不截屏、不录音、不读取音频内容。

## 素材管线

- ImageGen 生成 6 张 1024×1024 绿幕立绘：`maid` / `casual` 各 `idle`、`blink`、`happy`。
- `tools/build_sprites.py`：绿键 + 软 alpha + 去溢色 + 1px 腐蚀 + 脚底基线统一到 512×512 画布（脚底 y=500，角色高约 460）。
- 输出 `assets/sprites/{maid,casual}/*.png`、`assets/icons/tray.png`、`assets/icons/pet.ico`。
- 素材缺失回退 idle；全部缺失弹窗退出。

## 人格

安静、慢热、嘴软心硬、有一点自嘲。短句口语，常用「嗯 / 诶 / ……」，不客服腔、不奉承、不知道就说不知道、不制造愧疚。喜欢午后、摸头、看用户专注做事；不喜欢被猛拖、连戳、无视好几天。

UI 文案同样去机械化：菜单是「摸摸头」「一起专注」「回到原位」「先去睡了」。

## 记忆

`data/memory.json`：`first_seen`、`last_seen`、`days_seen`、`total_interactions`、`affection`、`pet_name`、`user_name`、`last_lines`、`habits`、`events`（上限 20，30 天清理）、`greeted_today`。

召回只做模糊模式（「最近总是这个点还在忙」），不暴露精确监控细节。

## 感知与作息

`perception.py` 用 ctypes 调 Win32，每 2 秒轮询：

- 前台进程只取 exe 名，映射为 `coding / meeting / browser / game / video / other`，原始名用完即弃。
- `GetLastInputInfo`：>60s 离开，>10min 久离。
- 全屏/会议/游戏 → 安静模式：不主动说话、不漫步，保留计时提醒。
- 02:00–06:00 睡眠；23:30–02:00 只提醒一次早睡；连续三晚才说「这周第三次」。
- 首次启动用一句气泡说明感知边界，菜单可关。

## 音频感应

`audio.py` 只读取系统默认播放设备的**音量峰值**，不录音、不取音频内容、不上传。后台线程 30Hz 轮询 WASAPI `IAudioMeterInformation`，按端点音量（`IAudioEndpointVolume`）归一化，静音时归零；每 10 秒重建设备，切换耳机/音箱后自动跟上，设备不可用时静默停用。

节奏判定（`MusicDetector`）：

- 慢速基线跟踪环境底噪；正向能量差超过自适应阈值（均值 + 1.6σ + 0.012）记为一拍，两拍至少间隔 0.3 秒。
- 对最近 4 秒的电平做自相关（30Hz 下 9–42 帧），存在明显周期结构才算「有节奏」；至少 3 拍、持续有声 ≥1 秒才进入音乐状态，安静 3.5 秒后退出。
- 由拍间隔估计 40–200 BPM 的速度；能量用慢起快落包络归一化，另给一个按拍衰减的脉冲值。
- 不识别歌曲或人声；环境噪声、键盘声、影视对白通常不触发。

## 关怀提醒

`care.py` 是纯逻辑调度器，每 30Hz tick 接收当前时间、空闲秒数和「不可打扰」状态，同一刻最多返回一条提醒。

- 问候：7:00 / 11:00 / 14:00 / 18:00 各一次；启动后的第一句算当前时段已问候，只在跨时段时出现；23:00–7:00 不问候。
- 吃饭：8:00 / 12:00 / 18:00 起 45 分钟窗口内提醒一次；错过窗口不补；吃饭视为一次休息，闭眼/喝水计时同时重置。
- 闭眼每 30 分钟、喝水每 60 分钟；同时到点合并成一句。离开 ≥5 分钟视为休息过，回来自动重新计时；2:00–6:00 暂停。
- 会议、手动「安静一会儿」、窗口隐藏、离开电脑时不弹；全屏视频/游戏照常提醒，恢复后若仍在有效窗口内会补一句。
- 优先级：吃饭 > 问候 > 喝水/闭眼；与久坐、整点报时同刻时关怀优先，番茄钟结束提醒例外。
- 每天的问候/吃饭状态写入 config，重启不重复。

## 对话

每条台词带 `event + tags`（时间/活动/心情/关系）。按上下文过滤后加权随机。

- 主动开口限流：安静 10min / 正常 4min / 话痨 90s。
- 互动后 45 秒内不追第二句；追问概率 18%，1.5–3 秒后出现，用户一动就取消。
- 约 12% 点击只歪头不说话，8% 只回「……」。
- 同事件最近 10 条不复用；最近 3 句不以相同两字开头。
- 亲昵台词：关系进入熟悉、或好感 ≥12 后，主动开口有 15% 概率说「想你 / 喜欢你」一类的话；更直白的版本只对亲近关系开放。

## 行为

状态：`IDLE / WANDER / DRAG / POKE / PET / ANNOYED / NAP / SLEEP / FALL`，`QUIET` 是模式。

- 点完 180–450ms 才回应。
- 4 秒内连点 3 次 → 转身背对 8 秒；碰到裙摆立刻转身 3.5 秒。
- 按立绘部位命中，透明处不响应：头顶/头发摸头、脸戳、身体戳、袖口击掌、裙摆、脚踝。各部位台词、表情、心情不同。
- 点脚踝会缩一下；双击轻跳一下；摸头有概率轻跳；击掌有星星。
- 闲置 20–50 秒随机微动作：看左右、重心偏移、理头发、打哈欠、伸懒腰。
- 漫步 60px/s、3–8 秒，30% 概率中途停一下，走动时带轻微摇摆。
- 拖到半空松手会受重力下落，在任务栏上弹跳两下、落地压扁。
- 甩出去的力度会保留：水平方向带惯性滑行，撞屏幕左右边缘和顶部会反弹，落地后受摩擦慢慢停住。
- 拖动时按鼠标速度倾斜、按上下速度拉伸；拎住超过 1.6 秒开始挣扎摆动、表情转不耐烦，2.4 秒后打断当前气泡抱怨一句。
- 落在普通窗口标题栏上沿时会站住；窗口最小化、被移走或她走出边缘时才继续下落。
- 也能站在窗口内部的输入框上沿（聊天/办公软件输入框、浏览器地址栏、支持 UI Automation 的 Edit 控件）；输入框被其他窗口盖住、窗口移动或关闭时自动下落。
- 听到有节奏的音乐时按拍轻晃（摆幅随口沿能量变化），低声时眨眼害羞、中等时开心、强节奏时闪光眼，强拍偶尔轻跳；头顶飘两枚音符。音乐开始/结束各有一句，长时间播放时可能主动说一句；安静模式或手动静音不反应。
- 输入框位置由后台线程用 UI Automation 扫描，只取控件类型和矩形，不读取输入内容；拖动时触发全量扫描，站在输入框上时只刷新宿主窗口，空闲不扫描。微信这类自绘输入框识别不到。
- 菜单可「记住这个位置」与「回到原位」；番茄钟结束时若已隐藏，会发系统托盘通知。
- 用户离开 >10 分钟打盹；回来伸懒腰 + 「你回来了」。
- 退出说「那我先睡了。明天见。」

## 心情与关系

- 心情 0–100，初始 70；摸头 +3、戳身体 +2、戳脸 +1、击掌 +2、碰裙摆 -4、碰脚 +1、双击 +5、猛拖 -2、完成专注 +8；每 15 分钟衰减 1。
- 关系 0–100：初识 / 熟悉 / 亲近；每天见面 +1、每 15 次互动 +1。熟悉后才在回来时打招呼；亲近后才叫昵称、靠近光标、道别。
- 不惩罚缺席，不说「你怎么才来」「别丢下我」。

## 窗口与气泡

- 窗口 248×216，无边框、逐像素透明、置顶、`Qt.Tool` 不进任务栏、不抢焦点。
- 精灵按 0.4 绘制（原 0.6 的 2/3），脚底在 (124, 200)；支持翻转、倾斜、呼吸、跳跃、压扁、被拎起时拉伸与挣扎。
- 气泡独立窗口，奶油底 `#F0EEE6`、橙色描边 `#D97757`、圆角 12、最大宽 260、微软雅黑 10.5pt、正文 `#3D3929`。
- 打字节奏：每字约 28ms，「，」停 120ms，「。」停 220ms；淡入 200ms、停留 4s（计时 6s）、淡出 250ms。
- 跟随头顶，空间不足改到脚下，水平钳制在屏幕内。

## 菜单与设置

右键桌宠和托盘的菜单共用同一个「设置」子菜单，勾选状态与 `config.json` 同步：

- 允许甩抛：关闭后拖动松手只受重力下落，不再保留甩出速度；打开后恢复撞边反弹。
- 随音乐反应：关闭后停止音频线程并清空音乐状态，音符、摇摆和音乐台词一并消失；打开立即重新监听。
- 关怀提醒 ▸ 定时问候 / 闭眼休息 / 喝水 / 吃饭：四个独立开关，默认全开；重新打开闭眼或喝水时从当下重新计时，问候不会中途补发。
- 久坐提醒 / 整点报时 / 环境感知 / 始终置顶 / 话多程度。

## 持久化

`data/config.json`：位置、服装、心情、心情时间戳、安静截止、设置（久坐/整点/置顶/感知/话量/甩抛/音乐/四项关怀）、番茄钟（阶段、ends_at）、关怀状态（日期、已问候时段、已提醒餐次）。

原子写入；损坏备份 `config.bad.json` 后回默认值。

## 验收

1. 首次启动问候 + 感知说明，不弹模态框。
2. 连续写代码 20 分钟：最多 4 分钟一句，不连发。
3. 会议/全屏：零主动气泡、零漫步。
4. 离开 15 分钟：打盹；回来伸懒腰 + 问候。
5. 4 秒连点 3 次：闹脾气、转身 8 秒。
6. 六个部位各有不同台词/表情/心情；双击轻跳；可甩抛、撞边反弹、站在窗口标题栏和输入框上沿；关掉「允许甩抛」后松手不再飞出；拎久了会挣扎抱怨；隐藏时番茄钟结束有托盘通知。
7. 深夜只提醒一次；连续三晚才有「这周第三次」。
8. 第七天纪念台词出现一次。
9. 台词防重复、限流、安静模式生效。
10. 重启后位置/心情/服装/关系恢复；第二实例退出；空闲 CPU <3%。
11. 播放节奏明显的音乐：她跟拍轻晃、换表情、冒音符；关掉「随音乐反应」后立刻停下，重开后恢复；设置菜单的勾选与重启后的状态一致。
12. 跨时段出现问候，早餐/午餐/晚餐在窗口内各提醒一次；30 分钟闭眼、60 分钟喝水，撞在一起合并；会议/手动安静/离开时不弹，全屏视频或游戏照常提醒；四个开关各自生效，重启后当天不重复。
