# Claude 拟人 Q 版桌宠 · V2 设计

日期：2026-10-31
目录：`D:\桌宠`

## 目标

一个 Windows 本地桌面宠物：橘发向日葵女仆「小橘」，2.5 头身 Q 版。它像一个有记忆、有作息、有小脾气的人，而不是随机播台词的动画。纯 Python + PySide6，无网络、无遥测。

## 非目标

不做安装包、开机自启、多宠物、语音、Live2D、联网 LLM、自动更新；不读窗口标题、不记录按键、不截屏、不录音、不读取音频内容。

## 素材管线

- ImageGen 生成 6 张 1024×1024 绿幕立绘：`maid` / `casual` 各 `idle`、`blink`、`happy`。
- 新装扮每套生成 `idle`、`happy` 两张（图生图，参考便服两帧；happy 帧要求画面左侧手臂举起挥动，与便服 happy 同姿势）；`blink` 由 `tools/port_blink.py` 从基础角色眨眼帧移植眼部区域（分块 SAD 对齐 + 尺度搜索，失败才补生成）。
- `tools/clean_raw.py`：去掉生成图右下角「AI 生成」水印（保留最大连通域）。
- `tools/build_sprites.py`：绿键 + 软 alpha + 去溢色 + 1px 腐蚀 + 脚底基线统一到 512×512 画布（脚底 y=500，角色高约 460）。
- 输出 `assets/sprites/{12 套}/*.png`、`assets/icons/tray.png`、`assets/icons/pet.ico`。
- 素材缺失回退 idle；全部缺失弹窗退出。

## 人格

安静、慢热、嘴软心硬、有一点自嘲。短句口语，常用「嗯 / 诶 / ……」，不客服腔、不奉承、不知道就说不知道、不制造愧疚。喜欢午后、摸头、看用户专注做事；不喜欢被猛拖、连戳、无视好几天。

UI 文案同样去机械化：菜单是「摸摸头」「一起专注」「回到原位」「先去睡了」。

## 记忆

`data/memory.json`：`first_seen`、`last_seen`、`days_seen`、`total_interactions`、`affection`、`pet_name`、`user_name`、`last_lines`、`habits`、`events`（上限 20，30 天清理）、`greeted_today`。

## 感知与作息

`perception.py` 用 ctypes 调 Win32，每 2 秒轮询：

- 前台进程只取 exe 名，映射为 `coding / meeting / browser / game / video / other`，原始名用完即弃。
- `GetLastInputInfo`：>60s 离开，>10min 久离。
- 全屏/会议/游戏 → 安静模式：不主动说话、不漫步，保留计时提醒。
- 02:00–06:00 睡眠；23:30–02:00 只提醒一次早睡；连续三晚才说「这周第三次」。
- 首次启动用一句气泡说明感知边界，菜单可关。

## 音频感应

`audio.py` 只读取系统默认播放设备的**音量峰值**，不录音、不取音频内容、不上传。后台线程 30Hz 轮询 WASAPI `IAudioMeterInformation`，按端点音量（`IAudioEndpointVolume`）归一化，静音时归零；每 10 秒重建设备，切换耳机/音箱后自动跟上，设备不可用时静默停用。

节奏判定（`MusicDetector`）：

- 慢速基线跟踪环境底噪；正向能量差超过自适应阈值（均值 + 1.6σ + 0.012）记为一拍，两拍至少间隔 0.3 秒。
- 对最近 4 秒的电平做自相关（30Hz 下 9–42 帧），存在明显周期结构才算「有节奏」；至少 3 拍、持续有声 ≥1 秒才进入音乐状态，安静 3.5 秒后退出。
- 由拍间隔估计 40–200 BPM 的速度；能量用慢起快落包络归一化，另给一个按拍衰减的脉冲值。
- 不识别歌曲或人声；环境噪声、键盘声、影视对白通常不触发。

## 关怀提醒

`care.py` 是纯逻辑调度器，每 30Hz tick 接收当前时间、空闲秒数和「不可打扰」状态，同一刻最多返回一条提醒。

- 问候：7:00 / 11:00 / 14:00 / 18:00 各一次；启动后的第一句算当前时段已问候，只在跨时段时出现；23:00–7:00 不问候。
- 吃饭：8:00 / 12:00 / 18:00 起 45 分钟窗口内提醒一次；错过窗口不补；吃饭视为一次休息，闭眼/喝水计时同时重置。
- 闭眼每 30 分钟、喝水每 60 分钟；同时到点合并成一句。连续静止满 10 分钟才算离开：短于一档的离开只暂停计时（回来后接着数完剩下的），长于一档的离开才重新计时；2:00–6:00 暂停。
- 会议、手动「安静一会儿」、窗口隐藏、离开电脑时不弹；全屏视频/游戏照常提醒，恢复后若仍在有效窗口内会补一句。
- 优先级：吃饭 > 问候 > 喝水/闭眼；与久坐、整点报时同刻时关怀优先，番茄钟结束提醒例外。
- 每天的问候/吃饭状态写入 config，重启不重复。

## 对话

每条台词带 `event + tags`（时间/活动/心情/关系）。按上下文过滤后加权随机。

- 主动开口限流：安静 10min / 正常 4min / 话痨 90s。
- 互动后 45 秒内不追第二句；追问概率 18%，1.5–3 秒后出现，用户一动就取消。
- 约 12% 点击只歪头不说话，8% 只回「……」。
- 菜单「说句话」走独立的强制台词，不受 6 秒限流、沉默概率或生气状态影响，必有回应。
- 同事件最近 10 条不复用；最近 3 句不以相同两字开头。
- 亲昵台词：关系进入熟悉、或好感 ≥12 后，主动开口有 15% 概率说「想你 / 喜欢你」一类的话；更直白的版本只对亲近关系开放。

## 语句库

`lines/` 按场景拆成四个模块，聚合后仍是扁平的 `LINES` 列表，调用方无感知：

- `interactions.py`：点、摸头、戳脸、击掌、裙摆、脚踝、双击、说话、拖拽/落地/叫醒/闹脾气。
- `daily.py`：发呆、写代码、闲逛、问候/回归、亲昵、退出、安静、起名；追问与夸奖表也在末尾。
- `companion.py`：整点、久坐、番茄钟、深夜、会议结束、关怀、音乐。
- `system.py`：换装、纪念日、感知开关、话量、记忆清空。

共 1400+ 条，63 个事件每个至少 8 条，单条不超过 34 字。新增内容参考了现有桌宠/虚拟伴侣的公开台词风格（MateEngine、VPet、desk_cat 等），全部重写不搬运；整体更黏人，但「想你 / 喜欢你」一类的直白版本仍只挂在 `close` 标签上，`familiar` 只到半句为止。`tests/test_lines.py` 校验总量、事件覆盖、单事件去重、标签合法性与文案长度。

## 行为

状态：`IDLE / WANDER / DRAG / POKE / PET / ANNOYED / NAP / SLEEP / FALL / ACTION`，`QUIET` 是模式。

- 点完 180–450ms 才回应。
- 4 秒内连点 3 次 → 转身背对 8 秒；碰到裙摆立刻转身 3.5 秒。
- 按立绘部位命中，透明处不响应：头顶/头发摸头、脸戳、身体戳、袖口击掌、裙摆、脚踝。各部位台词、表情、心情不同。
- 点脚踝会缩一下；双击轻跳一下；摸头有概率轻跳；击掌有星星。
- 闲置 20–50 秒随机微动作：看左右、重心偏移、理头发、打哈欠、伸懒腰。
- 表情叠加 13 种：blush / heart / annoyed / surprised / sparkle / wink / tears / pout / confused / shy / dizzy / sweat / expect（happy 走头部帧；wink 的闭眼直接贴本套 `blink` 帧左眼区域，避免矢量遮罩盖不住不同立绘的眼睛）。互动按部位和次数映射（如第二次戳脸鼓脸、戳身体疑惑、拎久冒汗、快速甩出晕），闲置偶发疑惑/期待/鼓脸，冷落太久偶尔泪光。
- 8 个短时动作（2.2–4 秒）：伸懒腰、东张西望、招手、打哈欠、喝水、吃点心、打伞、看书。菜单「做点什么」可手动触发；闲置轮换前四项；喝水/吃饭提醒联动喝水/吃点心，番茄钟联动看书；每个动作配专属台词，`PetState.action` 驱动分层骨架手势。
- 4 个道具（杯子、饼干、书、伞）用 QPainter 矢量绘制在精灵坐标系的手部锚点，12 套装扮通用；打伞时伞盖举过头顶并落雨滴。
- 漫步 60px/s、3–8 秒，30% 概率中途停一下，走动时带轻微摇摆。
- 拖到半空松手会缓慢飘落（200px 约 1 秒），触地前按距离减速，落地只轻轻一蹲、不再回弹。
- 甩出去的力度会保留（总速度封顶 1800px/s，飞行期 60fps 精确定时器 + 1/120 子步积分保证平滑），撞左右边缘/顶部轻反弹，低速贴墙直接停住；贴地滑行时支撑检测不再把桌面地板误判成“无支撑”而反复触发落地。
- 拖动时按鼠标速度倾斜、按上下速度拉伸；拎住超过 1.6 秒开始挣扎摆动、表情转不耐烦，2.4 秒后打断当前气泡抱怨一句。
- 落在普通窗口标题栏上沿时会站住；窗口最小化、被移走或她走出边缘时才继续下落。
- 也能站在窗口内部的输入框上沿（聊天/办公软件输入框、浏览器地址栏、支持 UI Automation 的 Edit 控件）；输入框被其他窗口盖住、窗口移动或关闭时自动下落。
- 听到有节奏的音乐时按拍轻晃（摆幅随口沿能量变化），低声时眨眼害羞、中等时开心、强节奏时闪光眼，强拍偶尔轻跳；头顶飘两枚音符。摇摆用平滑的相位累积，节拍估计的小幅波动不会让动作跳帧；频率封顶 1Hz，甩出的余震也从 8Hz 降到 2Hz 并带淡出。音乐开始/结束各有一句，长时间播放时可能主动说一句；安静模式或手动静音不反应。
- 输入框位置由后台线程用 UI Automation 扫描，只取控件类型和矩形，不读取输入内容；拖动时触发全量扫描，站在输入框上时只刷新宿主窗口，空闲不扫描。微信这类自绘输入框识别不到。
- 菜单可「记住这个位置」与「回到原位」；番茄钟结束时若已隐藏，会发系统托盘通知。
- 用户离开 >10 分钟打盹；回来伸懒腰 + 「你回来了」。
- 退出说「那我先睡了。明天见。」

## 2.5D 分层与换装

装扮共 12 套（女仆、便服、JK 水手服、居家睡衣、运动服、宽松毛衣、浴衣、旗袍、圣诞装、雨衣、风衣围巾、魔女），全部具备分层资产。是否出现在换装菜单由 `pet/outfits.py` 的资产检测决定：`assets/sprites/<id>/idle.png` 存在即可换；有 `assets/rig/<id>/rig.json` 就走分层，否则退回该套整张立绘。

- 分层：腿、身体、下垂手臂、侧发、头部（idle/blink/happy 三份）、抬起手臂，共 6 层。侧发暂时合并前后发，少一个接缝。
- 建库：`tools/build_rig.py` 按服装配置从现有 idle/blink/happy 三张 512 立绘切层；被发丝和手臂挡住的身体区域补色（便服补卫衣奶油色，女仆按邻域生长补黑裙/围裙色）；happy 头部以 idle 为底只换脸部；抬手层便服取奶油色袖子，女仆取肤色手/袖口和黑色袖子。`--check` 按原顺序叠回，平均 RGB 差 ≤3/255、alpha 覆盖率差 ≤0.5%。
- 女仆差异：裙摆花边到 y≈435，腿部从 y=436 起切；抬手位置比便服低，袖子为黑色，因此抬手层按肤色加袖口和黑色袖子分别提取。
- 待机：身体 3.6 秒呼吸，头部晚半拍，侧发再晚一点；倾斜时按层深度做视差。
- 局部反应：摸头压头和侧发；戳脸缩头回弹；点击手部击掌时抬起 `arm_up` 并隐藏下垂手臂；拖拽时腿绕髋下垂；落地压扁并让发梢过冲；动作模式下抬手层按动作摆到对应位置。
- 惯性：走路、音乐、甩出只驱动侧发和身体的弹簧滞后；音乐仍用封顶 1Hz 的相位，不新增抖动源。音乐强拍的 `sparkle` 眼睛不会触发抬手。
- 跟拍不木板化：头与躯干作为一个刚体绕髋轻晃（≤1.6°），表情的侧倾也交给躯干，头部不再单独平移或缩放；只有侧发滞后，腿层反向抵消全局旋转，脚下站稳。脸部叠加层随躯干一起转，不会在脸上滑动。
- 悬停：鼠标停在身上时她缓缓侧倾最多 2.5°，用弹簧跟随，快速划过只轻微动一下，离开时缓回零，不瞬间弹回。
- 落地：9% 浅蹲用 220ms 缓慢建立、650ms 收回，触地不再回弹；高速下落也不会一帧硬停。
- 帧率：Windows 的粗粒度定时器会把 33ms 抬到约 47ms（≈21fps），这是刻意保留的——精确定时器下 30fps 实测占用从 2.9% 升到 7.2%，超过空闲 CPU <3% 的底线；甩出/下落仍走 16ms。
- 回退：某服装的 `rig.json` 或任一图层缺失时记一条日志并退回该服装的平面渲染。
- 不变量：脚底锚点、窗口尺寸、点击 alpha 命中、气泡跟随、表情矢量叠加、zzz 与音符位置都不变。

## 心情与关系

- 心情 0–100，初始 70；摸头 +3、戳身体 +2、戳脸 +1、击掌 +2、碰裙摆 -4、碰脚 +1、双击 +5、猛拖 -2、完成专注 +8；每 15 分钟衰减 1。
- 关系 0–100：初识 / 熟悉 / 亲近；每天见面 +1、每 15 次互动 +1。熟悉后才在回来时打招呼；亲近后才叫昵称、靠近光标、道别。
- 不惩罚缺席，不说「你怎么才来」「别丢下我」。

## 窗口与气泡

- 窗口 248×216，无边框、逐像素透明、置顶、`Qt.Tool` 不进任务栏、不抢焦点。
- 精灵按 0.4 绘制（原 0.6 的 2/3），脚底在 (124, 200)；支持翻转、倾斜、呼吸、跳跃、压扁、被拎起时拉伸与挣扎。
- 气泡独立窗口，奶油底 `#F0EEE6`、橙色描边 `#D97757`、圆角 12、最大宽 260、微软雅黑 10.5pt、正文 `#3D3929`。
- 打字节奏：每字约 28ms，「，」停 120ms，「。」停 220ms；淡入 200ms、停留 4s（计时 6s）、淡出 250ms。
- 跟随头顶，空间不足改到脚下，水平钳制在屏幕内。

## 菜单与设置

右键桌宠和托盘的菜单共用同一个「设置」子菜单，勾选状态与 `config.json` 同步：

- 允许甩抛：关闭后拖动松手只受重力下落，不再保留甩出速度；打开后恢复撞边反弹。
- 随音乐反应：关闭后停止音频线程并清空音乐状态，音符、摇摆和音乐台词一并消失；打开立即重新监听。
- 关怀提醒 ▸ 定时问候 / 闭眼休息 / 喝水 / 吃饭：四个独立开关，默认全开；重新打开闭眼或喝水时从当下重新计时，问候不会中途补发。
- 久坐提醒 / 整点报时 / 环境感知 / 始终置顶 / 话多程度。
- 换装 ▸：由 `pet/outfits.py` 生成菜单，只列出已有资产的装扮，当前选中项打勾。
- 做点什么 ▸：8 个动作，手动触发一次短时动作并说一句对应台词。
- 开机自动启动：写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（值 `XiaoJuDesktopPet`，命令为 `"<pythonw.exe>" "<D:\桌宠\main.py>"`），不需要管理员；启动时按配置校正注册表，写失败回滚勾选并在气泡里说明。

## 持久化

`data/config.json`：位置、服装、心情、心情时间戳、安静截止、设置（久坐/整点/置顶/感知/话量/甩抛/音乐/四项关怀/自启动）、番茄钟（阶段、ends_at）、关怀状态（日期、已问候时段、已提醒餐次）。

原子写入；损坏备份 `config.bad.json` 后回默认值。

## 验收

1. 首次启动问候 + 感知说明，不弹模态框。
2. 连续写代码 20 分钟：最多 4 分钟一句，不连发。
3. 会议/全屏：零主动气泡、零漫步。
4. 离开 15 分钟：打盹；回来伸懒腰 + 问候。
5. 4 秒连点 3 次：闹脾气、转身 8 秒。
6. 六个部位各有不同台词/表情/心情；双击轻跳；可甩抛、撞边反弹、站在窗口标题栏和输入框上沿；关掉「允许甩抛」后松手不再飞出；拎久了会挣扎抱怨；隐藏时番茄钟结束有托盘通知。
7. 深夜只提醒一次；连续三晚才有「这周第三次」。
8. 第七天纪念台词出现一次。
9. 台词防重复、限流、安静模式生效。
10. 重启后位置/心情/服装/关系恢复；第二实例退出；空闲 CPU <3%。
11. 播放节奏明显的音乐：她跟拍轻晃、换表情、冒音符；关掉「随音乐反应」后立刻停下，重开后恢复；设置菜单的勾选与重启后的状态一致。
12. 跨时段出现问候，早餐/午餐/晚餐在窗口内各提醒一次；30 分钟闭眼、60 分钟喝水，撞在一起合并；会议/手动安静/离开时不弹，全屏视频或游戏照常提醒；读长内容这类几分钟静止不清零闭眼/喝水计时，四个开关各自生效，重启后当天不重复。
13. 语句库 1480+ 条、72 个事件全覆盖且单事件不重复；实机点击、摸头、说句话都能抽到新台词。
14. 便服与女仆待机都有呼吸与侧发滞后，摸头/戳脸/击掌/拖拽有局部反应，走路和音乐只有小幅惯性；切换服装后分层与点击命中正常，缺资产时回退平面；气泡与窗口尺寸不变；空闲 CPU <3%。
15. 12 种表情可由互动/闲置触发并在离屏与实机画面里可见；8 个动作可从菜单触发、时长结束自动回到待机，道具随分层手部锚点绘制，台词与动作匹配。
16. 换装菜单只显示已有资产的装扮，切换后分层、点击命中、气泡位置正常；新增素材目录后无需改代码即可出现在菜单。
17. 自启动开关写入/删除注册表项，重启后勾选状态一致；关闭后不再自启，目录变化时启动自动校正路径。
