# 便服小橘 2.5D 分层骨架设计

日期：2026-10-31
状态：待评审
范围：便服第一版；女仆装保持现有平面渲染

## 目标

把便服小橘从单张平面立绘升级为分层 2.5D：待机有呼吸和重心，互动有局部反应，走路、音乐、甩出时有发梢和身体的惯性滞后。不引入 Live2D/3D 运行时，继续用 QPainter 和现有窗口。

明确不做：

- 不做大角度转头、头部跟随鼠标。分层来自正面立绘，大幅旋转会露馅。
- 不改窗口尺寸、脚底锚点、气泡位置、点击命中区域。
- 女仆装第一版不动，后续用同一管线扩展。
- 不加新的运行时依赖；建库脚本只用 Pillow + numpy。

## 素材管线

新增 `tools/build_rig.py`，从 `assets/sprites/casual/` 的 idle / blink / happy 三张 512×512 立绘切层。

### 图层

从后到前：

1. `legs`：双腿，锚点在卫衣下摆。
2. `body`：奶白卫衣躯干与右臂，含口袋、抽绳、胸前小花。
3. `left_arm`：画面左侧的下垂手臂，从 idle 图切出；肩部锚点。
4. `side_hair`：搭在肩前和胸前的长发束，锚点靠近头部。
5. `head`：脸、头形、头顶头发、花饰与蝴蝶结；三份表情变体 `head_idle`、`head_blink`、`head_happy`。
6. `arm_up`：happy 图里抬起挥手的左臂，击掌或笑脸帧时替换 `left_arm`。

第一版先把后发和前发合并为一层 `side_hair`，少一个接缝；如果静态叠回或动作效果不足，再拆成前后两层。

被发丝、手臂遮住的卫衣区域，用从边界向内扩散的补色填充；卫衣以大面积平整色为主，补色后不应出现明显结构缺失。拆完先做叠回检查：按原顺序合成所有层，与原图逐像素比较，不透明区域的平均 RGB 差异 ≤3/255，alpha 覆盖率差异 ≤0.5%；肉眼看不到接缝才进入绑定。

### 输出

`assets/rig/casual/` 存放分层 PNG，`rig.json` 记录：

- 画布 512、脚底锚点 (256, 500)。
- 每层文件名、绘制顺序、深度值、局部锚点。
- 头部三份变体与手臂替换关系。

锚点先用几何估计，建库时按实际裁切微调并写回 `rig.json`，不写死在渲染器里：

- 脚底 (256, 500)，身体重心约 (256, 430)。
- 颈/头枢轴约 (256, 250)，发根约 (256, 130)。
- 画面左侧肩部约 (185, 275)，髋部约 (256, 400)，腿根约 (240, 415) 与 (272, 415)。

## 渲染

新增 `pet/rig.py`，负责层变换与弹簧状态；`pet/window.py` 只增加一个绘制分支。

### 分层绘制

- 新增 `RigLibrary`：加载 `rig.json` 与 QPixmap；缺失或损坏时返回 None，窗口自动回退到现有平面渲染，并只在日志里记一次。
- 新增 `Rig`：按 `rig.json` 顺序绘制，每层依次应用「脚底全局变换 → 层锚点 → 呼吸/重心 → 视差 → 弹簧旋转 → 反向锚点」。
- 深度视差：全局倾斜时按层深度产生反向错位，初始公式 `x = tilt_deg × (depth − 0.8) × 0.35px`，腿、身体、侧发、头、手臂幅度不同。
- 表情：`state.frame` 选择头部变体；`left_arm` 与 `arm_up` 按帧/表情替换。现有矢量表情叠加仍在最上层、同一坐标系内绘制。
- 点击命中和站立表面继续使用原立绘 alpha，不随分层移动。

### 动作

新增弹簧状态：头部位移、发梢角度、身体侧倾、腿部摆角、手臂进度。使用固定参数弹簧阻尼，`dt` 限制在 0–0.05 秒，所有输出限幅。

- 呼吸：3.6 秒周期，身体上下 ±0.5px、纵向缩放 ±0.6%，头部晚 0.3 秒，侧发再晚 0.25 秒。
- 重心：沿用现有 `tilt`，分层视差叠加；侧发和身体各取不同幅度，避免整张纸片一起晃。
- 部位识别：表情已经隐含来源（心=摸头、脸红=戳脸、sparkle=击掌），Rig 直接按 `state.expression` 驱动，不改 Behavior 状态机。
- 摸头：头部纵向压 4% 后回弹，侧发同步下压。
- 戳脸：头部沿受力方向后缩 1–2px，弹簧回位。
- 击掌（`sparkle` 表情）：隐藏 `left_arm`，显示 `arm_up`，绕肩锚点弹起约 0.35 秒；普通过笑笑脸不抬手。
- 拖拽：双腿绕髋向外下垂，身体随拖拽倾斜，头发反向滞后；甩出与落地沿用现有 squash，发梢追加过冲。
- 走路：按 `move_speed` 给头发和身体反向滞后，限幅 2px / 2°。
- 音乐：复用行为层已经封顶 1Hz 的 `music_phase` 与 `music_energy`，只驱动发梢和身体的小幅滞后，不新增独立抖动源。

### 接口

- `PetState` 增加 `music_phase`、`music_energy` 两个只读字段，由行为层填好；其余状态不变。
- `Rig.draw(painter, state, now, dt, overlay)`：`overlay` 是现有表情绘制回调，在层全部画完后、恢复全局变换前调用。
- 窗口在 `paintEvent` 里优先调用 Rig；Rig 不可用时走原路径。气泡、zzz、音符、阴影逻辑不动。

## 测试与验收

自动化：

- `tests/test_rig.py`：rig.json 解析与角色映射、缺素材回退、层顺序、锚点/视差方向、弹簧衰减与限幅、dt 上限、帧到头部变体的选择、手臂替换条件。
- 现有 99 个测试全部通过；女仆装旧渲染路径有回归覆盖。
- 建库脚本提供 `--check`，执行叠回对比并输出差异指标。

实机：

1. 便服静态叠回与原图无明显差异，无接缝、无缺块。
2. 待机呼吸可见但不夸张；重心变化时腿、身体、侧发、头部错位自然。
3. 摸头压发、戳脸缩头、击掌抬臂、拖拽腿下垂、落地发梢过冲均正常。
4. 走路、音乐、甩出时只有滞后和小幅摆动，没有高频抖动。
5. 侧发与身体、头部接缝在动作中不露底。
6. 点击六个部位仍准确；闭眼、笑脸、矢量表情、气泡、音符正常。
7. 换回女仆装与原来完全一致，再换回便服仍正常。
8. 30fps 下空闲 CPU <3%（单核），峰值 <6%；内存增量 <30MB。

## 风险

- 平面图拆层会有遮挡缺口：用补色 + 叠回检查 + 少量手工修饰控制，必要时缩小动作幅度。
- 头部三张变体可能有 1–2px 对位差：只用平移对齐，不做缩放；对不上的地方以 idle 为基准修边。
- 容易做成「纸片木偶」：所有常态动作限幅在 1–3°、2px 内，事件冲击才允许更大的瞬时位移。
- 性能：层数控制在 6 层，QPixmap 缓存，弹簧按 30Hz 更新，先用现有计时器，不额外开线程。
